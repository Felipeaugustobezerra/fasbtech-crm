# Modelo de Dados

## Tabelas iniciais

- users
- organizations
- leads
- clients
- projects
- products
- domains
- hosting_services
- financial_entries
- tasks
- notes

## Relações

- Uma organização possui vários utilizadores.
- Uma organização possui vários leads.
- Uma organização possui vários clientes.
- Um cliente possui vários projetos.
- Um projeto pertence a um cliente.
- Um projeto pode possuir domínio e hospedagem.
- Um cliente pode possuir várias entradas financeiras.
- Leads, clientes e projetos podem possuir tarefas.
