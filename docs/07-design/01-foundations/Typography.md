# Typography

## Versão

1.0

---

# Objetivo

Este documento define a tipografia oficial da FASBtech.

Todos os produtos da empresa devem seguir estas regras para garantir:

- Consistência
- Legibilidade
- Hierarquia visual
- Acessibilidade

---

# Filosofia

A tipografia deve transmitir:

- Organização
- Tecnologia
- Clareza
- Precisão

O conteúdo deve ser mais importante que os elementos gráficos.

# Comprimento de Linha

Ideal:

60–80 caracteres

Nunca ultrapassar 100 caracteres em textos corridos.

---

# Ícones

Todo ícone deve possuir alinhamento visual com o texto.

Os ícones devem manter proporção visual adequada ao contexto.

Botões, menus e ações podem utilizar ícones maiores que o texto quando necessário para melhorar a usabilidade.

A prioridade é manter consistência visual e acessibilidade.

# Acessibilidade

Não utilizar:

- texto menor que 12px;
- contraste insuficiente;
- pesos muito finos.

---

# Boas Práticas

Utilizar:

- poucas variações de tamanho;
- pesos consistentes;
- espaçamento adequado;
- alinhamento à esquerda.

Evitar:

- textos centralizados em páginas internas;
- muitos pesos diferentes;
- excesso de caixa alta.

---

# Definition of Done

Toda nova tela deverá respeitar este documento.

Nenhum componente poderá definir tamanhos arbitrários de fonte.
