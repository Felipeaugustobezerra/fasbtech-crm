# Spacing

## Versão

1.0

---

# Objetivo

Este documento define o sistema oficial de espaçamento da FASBtech.

Todo componente deverá utilizar exclusivamente esta escala.

Nunca utilizar valores arbitrários.

---

# Filosofia

O espaçamento é responsável por criar:

- Organização
- Hierarquia
- Leitura
- Ritmo visual

Interfaces profissionais possuem muito mais relação com espaçamento do que com cores.

---

# Unidade Base

A FASBtech utiliza uma escala baseada em:

4px

Toda medida deverá ser múltipla de 4.
