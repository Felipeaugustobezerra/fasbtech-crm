# ADR-001 — Stack Tecnológica

## Status

Aprovado

## Decisão

Utilizar:

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Zod
- React Hook Form
- Vercel

## Motivo

A stack permite criar uma aplicação web responsiva, com banco em cloud, autenticação, boa experiência de desenvolvimento e possibilidade de expansão futura.

## Alternativas consideradas

- Firebase
- Banco local
- Express separado
- WordPress

## Consequências

### Positivas

- Banco em cloud.
- Autenticação pronta.
- Fácil deploy.
- Boa escalabilidade inicial.

### Negativas

- Dependência do Supabase.
- Necessidade de configurar políticas de segurança.
