# Histórias de Utilizador

## Cadastrar lead

Como administrador,
quero cadastrar um possível cliente,
para acompanhar o processo comercial.

### Critérios de aceite

- Nome obrigatório.
- E-mail deve ser válido.
- Status inicial deve ser "Novo".
- Data de criação deve ser automática.

---

## Converter lead em cliente

Como administrador,
quero converter um lead ganho em cliente,
para iniciar um projeto.

### Critérios de aceite

- O lead deve estar com status "Ganho".
- Os dados principais devem ser copiados.
- O lead não deve ser apagado.
- O sistema deve registrar a conversão.

---

## Registrar renovação

Como administrador,
quero registrar a data de renovação de um domínio,
para não esquecer o vencimento.

### Critérios de aceite

- Domínio obrigatório.
- Data de renovação obrigatória.
- Responsável pelo pagamento obrigatório.
