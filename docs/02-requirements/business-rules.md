# Regras de Negócio

1. Todo lead deve pertencer a uma organização.
2. Todo cliente pode possuir vários projetos.
3. Todo projeto deve estar associado a um cliente.
4. Um lead ganho pode ser convertido em cliente.
5. Um domínio pode estar associado a um cliente ou projeto.
6. Toda renovação deve possuir uma data.
7. Pagamentos podem ter os status:
   - previsto
   - pendente
   - pago
   - atrasado
   - cancelado
8. Projetos podem ter os status:
   - planejamento
   - aguardando conteúdo
   - design
   - desenvolvimento
   - revisão
   - homologação
   - publicado
   - concluído
   - pausado
   - cancelado
