# Requisitos Funcionais

## Autenticação

- O utilizador deve conseguir entrar com e-mail e senha.
- O utilizador deve conseguir sair do sistema.
- As páginas internas devem ser protegidas.

## Leads

- Criar lead.
- Editar lead.
- Excluir lead.
- Alterar status.
- Registrar próximo contato.
- Converter lead em cliente.

## Clientes

- Criar cliente.
- Editar cliente.
- Visualizar histórico.
- Associar projetos.

## Projetos

- Criar projeto.
- Associar cliente.
- Associar produto.
- Atualizar status.
- Registrar datas e valores.

## Domínios e hospedagens

- Registrar domínio.
- Registrar hospedagem.
- Registrar datas de renovação.
- Registrar responsável pelo pagamento.

## Financeiro

- Registrar valores previstos.
- Registrar pagamentos.
- Alterar status financeiro.

## Tarefas

- Criar tarefa.
- Definir prazo.
- Definir prioridade.
- Associar a lead, cliente ou projeto.
